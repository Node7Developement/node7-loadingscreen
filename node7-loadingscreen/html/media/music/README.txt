DROP YOUR MUSIC FILES HERE
==========================

Supported by Chromium/NUI: MP3, OGG, WAV.

Example:
  html/media/music/node7-theme.mp3

Then add it to html/config.js under music.tracks:

  {
    title: 'NODE7 THEME',
    artist: 'NODE7',
    src: 'media/music/node7-theme.mp3'
  }

You can add multiple tracks. The loading screen will cycle through them.
